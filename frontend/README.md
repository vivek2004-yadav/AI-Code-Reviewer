# AI Code Reviewer - Frontend

This is the frontend React application for the AI Code Reviewer. It provides an interactive code editor where users can write code, select their programming language, and receive instant AI-powered code feedback.

## 🛠️ Tech Stack

- **React.js** (built with **Vite**) - Frontend UI framework
- **Axios** - HTTP client for API requests
- **React Simple Code Editor** - In-browser code editor
- **PrismJS** - Syntax highlighting for multiple programming languages
- **React Markdown** & **Rehype Highlight** - Formatted markdown rendering for AI feedback
