# AI Code Reviewer - Backend

This is the backend server for the AI Code Reviewer application. It uses Express.js and Google Gemini AI to analyze code and generate automated code reviews for multiple programming languages.

## 🛠️ Tech Stack

- **Node.js** - JavaScript runtime
- **Express.js** - Web framework for Node.js
- **Google Gemini AI API** (`@google/generative-ai`) - AI engine for code reviews
- **dotenv** - Environment variable management
- **cors** - Cross-Origin Resource Sharing
